# Day/Night Weather Icons for 10-Day Forecast — Future Plan

## Context

The 10-day forecast currently shows a single emoji icon per day, derived only from
daytime hours. Nighttime conditions are completely ignored. The goal is to show the
predominant night condition alongside the day icon — but only when the night is
"notable" (precip, storms, snow, fog). This also upgrades from emojis to the
Basmilius Meteocons icon set (MIT license), which has proper day/night SVG variants
(sun vs moon-based icons).

Icon set: https://github.com/basmilius/weather-icons
CDN base: https://cdn.jsdelivr.net/gh/basmilius/weather-icons@2.0.0/production/fill/svg
License: MIT
Demo:    https://basmilius.github.io/weather-icons/index-fill.html

User choices (decided during planning):
  - Night icon shown: ONLY for notable nights (precip/storms/snow/fog, not clear/cloudy)
  - Layout: side by side (day left, night right)
  - Night icon style: dark pill background
  - Icon set: Basmilius Meteocons (replacing emojis in forecast only)

STEP 1: New file — src/utils/meteoconMap.js (~40 lines)
================================================================================

WMO code -> Basmilius icon name mapping + helper functions.

Exports:
  - WMO_TO_METEOCON object (28 WMO codes -> { day: 'name', night: 'name' })
  - getMeteoconUrl(wmoCode, isNight) -> full CDN URL string
  - meteoconImg(wmoCode, isNight, fallbackEmoji, cssClass) -> <img> HTML string
    with onerror emoji fallback for CDN failures

WMO-to-Meteocon mapping table:

  WMO 0   (Clear sky)              -> clear-day / clear-night
  WMO 1   (Mainly clear)           -> clear-day / clear-night
  WMO 2   (Partly cloudy)          -> partly-cloudy-day / partly-cloudy-night
  WMO 3   (Overcast)               -> overcast-day / overcast-night
  WMO 45  (Foggy)                  -> fog-day / fog-night
  WMO 48  (Rime fog)               -> fog-day / fog-night
  WMO 51  (Light drizzle)          -> partly-cloudy-day-drizzle / partly-cloudy-night-drizzle
  WMO 53  (Moderate drizzle)       -> overcast-day-drizzle / overcast-night-drizzle
  WMO 55  (Dense drizzle)          -> drizzle / drizzle
  WMO 56  (Light freezing drizzle) -> overcast-day-sleet / overcast-night-sleet
  WMO 57  (Heavy freezing drizzle) -> sleet / sleet
  WMO 61  (Slight rain)            -> partly-cloudy-day-rain / partly-cloudy-night-rain
  WMO 63  (Moderate rain)          -> overcast-day-rain / overcast-night-rain
  WMO 65  (Heavy rain)             -> extreme-rain / extreme-rain
  WMO 66  (Light freezing rain)    -> overcast-day-sleet / overcast-night-sleet
  WMO 67  (Heavy freezing rain)    -> sleet / sleet
  WMO 71  (Slight snow)            -> partly-cloudy-day-snow / partly-cloudy-night-snow
  WMO 73  (Moderate snow)          -> overcast-day-snow / overcast-night-snow
  WMO 75  (Heavy snow)             -> snow / snow
  WMO 77  (Snow grains)            -> snow / snow
  WMO 80  (Slight rain showers)    -> partly-cloudy-day-rain / partly-cloudy-night-rain
  WMO 81  (Moderate rain showers)  -> overcast-day-rain / overcast-night-rain
  WMO 82  (Violent rain showers)   -> extreme-rain / extreme-rain
  WMO 85  (Slight snow showers)    -> partly-cloudy-day-snow / partly-cloudy-night-snow
  WMO 86  (Heavy snow showers)     -> snow / snow
  WMO 95  (Thunderstorm)           -> thunderstorms-day-rain / thunderstorms-night-rain
  WMO 96  (Thunderstorm + hail)    -> thunderstorms-day-rain / thunderstorms-night-rain
  WMO 99  (Thunderstorm + hvy hail)-> thunderstorms-day-rain / thunderstorms-night-rain

Sample implementation:

  const METEOCON_CDN = 'https://cdn.jsdelivr.net/gh/basmilius/weather-icons@2.0.0/production/fill/svg';

  function getMeteoconUrl(wmoCode, isNight) {
      const entry = WMO_TO_METEOCON[wmoCode];
      if (!entry) return null;
      const name = isNight ? entry.night : entry.day;
      return `${METEOCON_CDN}/${name}.svg`;
  }

  function meteoconImg(wmoCode, isNight, fallbackEmoji, cssClass) {
      const url = getMeteoconUrl(wmoCode, isNight);
      if (!url) return fallbackEmoji;
      const cls = cssClass ? ` class="${cssClass}"` : '';
      return `<img src="${url}"${cls} alt="" loading="lazy"
              onerror="this.replaceWith(document.createTextNode('${fallbackEmoji}'))">`;
  }

Part B — Add new deriveNightlyIcons(hourly, daily) function (~45 lines):

  Algorithm (mirrors deriveDailyIcons but for nighttime):
  1. For each day in daily.time, collect hourly indices where:
     - hourly.time[h] starts with the day's date string
     - hourly.is_day[h] === 0  (nighttime)
  2. If no nighttime hours, push null and continue.
  3. Run the same precip-override cascade:
     - Thunder: >=2 thunder codes OR (>=1 + precip >= 0.05")
     - Snow: >=2 snow codes
     - Rain: (>=3 rain codes + precip) OR >=2 high-prob hours OR precip >= 0.05"
     - Fog: >=3 fog codes
  4. If any override fires -> push { ...getWeatherInfo(code), wmoCode: code }
     This is a "notable" night.
  5. If only sky-state scoring fires (clear/partly cloudy/overcast) -> push null
     NOT notable — no night icon displayed.

  Reuses existing constants: THUNDER_CODES, SNOW_CODES, RAIN_CODES, FOG_CODES,
  PRECIP_THRESHOLD.
